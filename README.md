# Endless Joyland

An ad-free amusement park idle game that installs on your phone.

Play: open the GitHub Pages link in Safari, tap Share, then Add to Home Screen.

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`: the built web app served by GitHub Pages
- `source/`: game source (`src/core.js` rules, `src/ui.js` interface, `src/index.html` layout). Run `node source/build.js` to rebuild.
